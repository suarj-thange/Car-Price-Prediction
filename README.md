# Car Price Prediction

This project predicts car prices based on features such as model, year, mileage, transmission, fuel type, and engine size.

## Objective
To build a regression model for accurate car price prediction.

## Models Used
- Linear Regression
- Random Forest Regressor
- Extra Trees Regressor
- CatBoost Regressor

## Outcome
CatBoost Regressor provided the best performance.

## Tools & Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- CatBoost
